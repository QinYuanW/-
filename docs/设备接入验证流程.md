# 设备接入验证流程（真实设备）

> 目的：验证「设备注册 → MQTT 连接鉴权 → 数据上报 → 控制台展示 → 指令下发 → 离线检测」全链路
> 适用：自己接入一台真实设备（ESP32）或模拟设备
> 日期：2026-09-05

***

## 0. 前置条件（当前已就绪）

| 组件            | 地址                                     | 状态    |
| ------------- | -------------------------------------- | ----- |
| EMQX          | localhost:1883（MQTT）/ 18083（Dashboard） | ✅ 运行中 |
| 后端            | <http://localhost:8080>                | ✅ 运行中 |
| 前端控制台         | <http://localhost:5173>                | ✅ 运行中 |
| MySQL / Redis | 3306 / 6379                            | ✅ 运行中 |

控制台登录：打开 <http://localhost:5173，账号> `admin` / `admin123`。

***

## 1. 注册设备

**方式 A：直接用现有演示设备**（最快，跳过本步）

- `device_key = dev_demo_001`

- `device_secret = demo_secret_123`

**方式 B：注册一台新设备**（推荐，验证注册接口）

```powershell
$body = @{ product_key="p_demo_001"; device_name="我的真实设备" } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:8080/api/v1/devices" -Method Post -ContentType "application/json" -Body $body
```

返回结果（**device\_secret 只返回一次，务必保存**）：

```json
{
  "code": 0,
  "data": {
    "device_key": "dev_xxxxx",
    "device_name": "我的真实设备",
    "device_secret": "a7e6e00afea86b2b2551ff5e91d4ded8"
  }
}
```

***

## 2. 设备连接 EMQX（MQTT）

连接参数（关键：**ClientID = Username = device\_key，Password = device\_secret**）：

| 参数       | 值                 |
| -------- | ----------------- |
| Broker   | `localhost:1883`  |
| ClientID | `{device_key}`    |
| Username | `{device_key}`    |
| Password | `{device_secret}` |
| QoS      | 1                 |

**验证点**：连接成功 = 鉴权通过。若失败，检查 device\_secret 是否正确、设备是否已注册。

***

## 3. 上报属性数据

**Topic**：`up/{device_key}/property`

**Payload**（JSON，key 必须匹配物模型属性）：

```json
{"temperature": 26.5, "humidity": 60, "switch": true}
```

p\_demo\_001 的物模型属性：

| 属性 key      | 类型    | 读写  | 单位 |
| ----------- | ----- | --- | -- |
| temperature | float | 只读  | ℃  |
| humidity    | float | 只读  | %  |
| switch      | bool  | 可读写 | —  |

**验证点**：

- 控制台「设备列表」该设备状态变为**在线**

- 「指标卡片」温度/湿度数值刷新

- 「历史曲线」出现新数据点

***

## 4. 控制台查看数据

打开控制台 → 选中该设备，依次核对：

1. **设备列表**：在线状态 = 在线
2. **指标卡片**：temperature / humidity 显示上报值
3. **历史曲线**：折线图随时间出现数据点

> 💡 设备较多时（如压测后几百台），在设备列表**搜索框**输入 `device_key` 或设备名即可快速定位；列表默认**在线设备排最前**。

***

## 5. 指令下发（验证下行链路，可选但推荐）

**控制台方式**：在设备详情页操作 `switch` 开关控件。

**接口方式**：

```powershell
$body = @{ command_type=1; payload=@{ switch=$true } } | ConvertTo-Json -Depth 3
Invoke-RestMethod -Uri "http://localhost:8080/api/v1/devices/dev_demo_001/commands" -Method Post -ContentType "application/json" -Body $body
```

返回 `request_id`，设备端应收到：

- **Topic**：`down/{device_key}/command`

- **Payload**：`{"request_id":"...","command_type":1,"payload":{"switch":true}}`

设备执行后回报 ACK：

- **Topic**：`up/{device_key}/ack`

- **Payload**：`{"request_id":"...","success":true}`

**验证点**：查询指令状态 `GET http://localhost:8080/api/v1/commands/{request_id}`，`status=2`（已执行）。若设备未回报，约 60s 后状态变 `4`（超时）。

***

## 6. 离线检测验证

停止设备上报并断开连接（或直接关掉 MQTT 客户端），等待约 **90 秒**（60s 心跳超时 + 30s 扫描周期）。

**验证点**：控制台设备状态变为**离线**；数据库 `device_log` 新增记录：

```sql
SELECT content, created_at FROM device_log
WHERE device_id = (SELECT id FROM device WHERE device_key='dev_demo_001')
ORDER BY created_at DESC LIMIT 5;
```

应看到「心跳超时离线（> 60s 无上报）」记录。

***

## 7. 真实 ESP32 设备接入

项目已提供 ESP32-S3 固件：`firmware/esp32_iot/`

1. 用 VSCode + ESP-IDF 打开 `firmware/esp32_iot`
2. 在 `main/hello_world_main.c` 或 `main/iot/platform_mqtt.c` 中配置：

   - WiFi 账号密码

   - `device_key` / `device_secret`（用第 1 步注册的）

   - Broker 地址（局域网内填电脑 IP，如 `192.168.x.x:1883`）
3. 编译烧录，串口监视器观察连接与上报日志
4. 重复第 3-6 步验证

> 参考：`tmp/sim_device.py` 是完整的模拟设备脚本（连接 + 订阅下行 + 回报 ACK），可先跑通再移植到固件。

## 附：常见问题

| 现象         | 原因                  | 处理                                    |
| ---------- | ------------------- | ------------------------------------- |
| 连接被拒（rc=5） | 凭据错误                | 核对 device\_key/secret，重新注册            |
| 连接被拒（rc=4） | 设备未注册               | 先调注册接口                                |
| 上报后控制台无数据  | Topic 或 payload 格式错 | 确认 `up/{key}/property` + 属性 key 匹配物模型 |
| 指令下发后设备无响应 | 设备未订阅下行 Topic       | 确认订阅 `down/{key}/command`             |
| 设备一直在线     | 还在上报                | 停止上报后等 90s 再看                         |
