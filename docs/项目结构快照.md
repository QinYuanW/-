## 一、运行时拓扑（docker-compose 6 服务）

| 服务 | 镜像 | 端口 | 角色 |
|---|---|---|---|
| `emqx` | emqx/emqx:5.8 | 1883 / 8883 / 18083 | MQTT 接入（认证器 + 规则引擎 → Kafka） |
| `redis` | redis:7.2 | 6379 | 设备凭据缓存 / 在线状态窗口协调 |
| `kafka` | apache/kafka:3.9.0 | 9092 | 单节点 KRaft，双 listener（DOCKER `kafka:29092` / HOST `localhost:9092`） |
| `prometheus` | prom/prometheus:v2.53.2 | 9090 | 指标抓取 + 告警规则求值 |
| `grafana` | grafana/grafana:11.2.0 | 3000 | 大盘可视化 |
| `alertmanager` | prom/alertmanager:v0.27.0 | 9093 | 告警路由（→ 飞书，⚠️ 见 B6） |

> MySQL 5.7 跑在宿主机（非容器），数据目录 `D:\AppData\MySQLData`。

## 二、数据链路（D1 / D2）

```
设备(ESP32) --MQTT--> EMQX --规则引擎--> Kafka topic: iot.telemetry (key=device_key)
                                              │
                           消费者组 iot-telemetry-consumers
                                              │  成功
                                              ▼
                    TelemetryServiceImpl.processSync → MySQL device_telemetry
                        ├─ insertBatch：multi-values INSERT + ON DUPLICATE KEY UPDATE id=id（幂等，D2-1）
                        └─ refreshOnline：5s 窗口聚合刷 device 表

                        失败（非永久）
                                              ▼
                  @RetryableTopic 非阻塞重试阶梯：-retry-0 → -retry-1 → -retry-2
                                              │ 耗尽 / 永久失败（PermanentTelemetryException，被 exclude）
                                              ▼
                                    iot.telemetry-dlt（死信，可人工重放）
```

**关键设计**：`AckMode.RECORD`（容器托管提交）+ 失败消息**离开主分区** → 根除"失败记录被后续 ack 越过"的静默丢数据（BUG-21）。详见 `docs/05_压测报告/D2-2_消费端ack语义实验报告.md`。

## 三、关键包职责（iot-platform）

| 包 | 职责 |
|---|---|
| `client` | EmqxClient：调 EMQX `/api/v5/publish`（API Key + HTTP/1.1） |
| `controller` | Auth（EMQX 认证回调）/ Telemetry（上报接收 → 投 Kafka）/ Device（查询 + TSL + 遥测）/ Command（下发 + 回报）/ User（登录） |
| `listener` | **TelemetryKafkaListener**：Kafka 消费入口；`@RetryableTopic(attempts=4, 退避 1→2→4s, exclude=永久失败, dltSuffix="-dlt")` + `@DltHandler` |
| `service.impl` | CommandServiceImpl（超时扫描 + ack 幂等）；UserServiceImpl（BCrypt + JWT）；**TelemetryServiceImpl**（批量幂等入库 + 在线状态窗口聚合 + 失败分级） |
| `config` | AsyncConfig（削峰线程池）/ **KafkaConfig（acks=all + AckMode.RECORD）** / **MetricsConfig（Micrometer）** / EmqxProperties / JwtProperties / Redis / MyBatis-Plus / WebMvcConfig（注册拦截器） |
| `health` | **EMQXHealthIndicator**：`/actuator/health` 的 EMQX 探活 |
| `interceptor` | JwtInterceptor：`/api/v1/**` 强制鉴权，放行 `/login` + `/auth` + `/telemetry` + `/commands/ack` |
| `common` | Result / ErrorCode / BizException / GlobalExceptionHandler / **PermanentTelemetryException（永久失败标记，跳过重试直达 DLT）** |
| `util` | JwtUtil：JWT 签发/解析（HS384，secret 来自 `jwt.secret`） |
| `mapper` | MyBatis-Plus；DeviceTelemetryMapper 含 `selectLatestByDevice` + `insertBatch`（幂等） |
| `dto` / `entity` | 入参出参 VO（snake_case 映射）/ 11 张表实体（deleted 软删 `@TableLogic`） |
