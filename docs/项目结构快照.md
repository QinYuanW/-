## 关键包职责（iot-platform）

| 包 | 职责 |
|---|---|
| `client` | EmqxClient：调 EMQX `/api/v5/publish`（API Key + HTTP/1.1） |
| `controller` | Auth（鉴权回调）/ Telemetry（上报接收）/ Device（查询+TSL）/ Command（下发+回报）/ User（登录） |
| `service.impl` | 业务实现；CommandServiceImpl 含超时扫描 + ack 幂等；UserServiceImpl 含 BCrypt 校验 + JWT 签发 |
| `config` | AsyncConfig（削峰线程池）/ EmqxProperties / JwtProperties / Redis / MyBatis-Plus / WebMvcConfig（注册拦截器） |
| `interceptor` | JwtInterceptor：`/api/v1/**` 强制鉴权，放行 `/login` + `/auth` + `/telemetry` + `/commands/ack` |
| `util` | JwtUtil：JWT 签发/解析（HS256，secret 来自 jwt.secret） |
| `mapper` | MyBatis-Plus；DeviceTelemetryMapper 含 selectLatestByDevice SQL |
| `dto` | 入参/出参 VO（snake_case 映射） |
| `entity` | 7 张表实体（deleted 软删 @TableLogic） |
