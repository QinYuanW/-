## 一、设计参照：OneNET 控制台

### 1.1 OneNET 设备管理信息架构（浓缩）

```
设备接入与管理                运维监控                  应用开发
├── 产品管理                  ├── 设备调试              ├── 规则引擎 / 场景联动
│   └── 产品详情               ├── API 调试 / 日志服务    ├── 数据推送
│       └── 物模型管理          ├── 数据看板              └── 应用 API
├── 设备管理                  └── 远程升级（OTA）
│   ├── 设备列表（单个/批量添加、搜索、导出、批次列表）
│   └── 设备详情（设备信息 / 物模型数据 / 事件记录 / 服务调用 / 命令下发 / 分组标签 / 操作记录）
└── 分组管理（分组列表 + 分组详情：标签 key/value、设备增删）
```

关键设计语言：**产品 → 设备的两级组织**、**设备详情是 tab 化工作台**、**「调试」作为独立工作区**（属性设置/服务调用实时看返回）。

### 1.2 差异对照与借鉴动作

| OneNET 页面 | iot-console 现状 | 借鉴动作 | 优先级 |
|------------|----------------|---------|:--:|
| 左侧主导航（模块级） | 仅顶栏 + Console 内联布局，无全局导航 | 引入左侧主导航：控制台 / 产品与物模型 / 设备分组 / 规则引擎 / 固件升级（Grafana 运维盘外链） | 高 |
| 设备列表（状态筛选/批量/导出/批次） | 有搜索/产品筛选/分页/在线置顶；缺状态筛选、批量操作、批次列表 | 设备列表页增强（见 3.2） | 中 |
| 设备详情 tab 工作台 | 选中设备后主区面板平铺（数据/曲线/控制/影子） | 独立详情页 + tab 结构（见 3.1） | 高 |
| 设备调试（属性设置/服务调用看返回） | ControlPanel 已覆盖下发控制 + 服务按钮 | 并入详情页「调试」tab，能力已具备，做布局归位 | 中 |
| 物模型管理（属性/事件/服务编辑） | Products.vue 已实现（属性为主） | 补齐事件/服务编辑表单（E5 已完成，缺口在 UI） | 中 |
| 分组管理（标签 key/value、单分组归属） | 无 | E4 按 OneNET 形态落地（见 3.6） | 按 E4 |
| 远程升级（升级包/任务/设备任务状态） | 无 | F1 按 OneNET 形态落地（见 3.7） | 按 F1 |
| 数据看板 / 拖拽大屏 | Grafana 运维大盘（外部） | 产品级看板**暂缓**（见「暂缓/不做」） | — |

> 借鉴原则：**学信息架构与交互形态，不照抄视觉皮肤**；拖拽式大屏、开放 API 等已 descope 的能力不因参照而复活。

### 1.3 参考产品：FastBee + JetLinks（2026-09-13 决策）

OneNET 提供信息架构骨架，FastBee / JetLinks 提供可直接感知的**企业级视觉与交互细节**，三者在页面级的分工：

| 参考产品 | 借鉴点 | 落地位置 |
|---------|--------|---------|
| FastBee（iot.fastbee.cn） | 控制台整体风格：左侧分组导航（设备管理/运维监控等）、顶栏面包屑、统计卡片条（总数/在线/离线/产品数） | `AppLayout.vue`（分组导航 + 面包屑）、`Console.vue`（stats-bar） |
| JetLinks（demo.jetlinks.cn） | 设备详情页 tab 化工作台（设备信息/实时数据/调试/影子/事件/日志）、物模型驱动的属性卡片与控件渲染 | `DeviceDetail.vue` 6 tab、`MetricCards` / `ControlPanel` 按 TSL 渲染 |
| 两者共同 | 物模型三要素（属性/服务/事件）+ 类型体系（int/float/bool/string/**enum** 等） | `Products.vue` 物模型编辑器（enum 枚举项 + step 步长） |

落地差异（不照搬项）：不做 JetLinks 的租户/权限树，不做 FastBee 的云端日志页签体系；分组/规则/OTA 菜单留待对应阶段完成后再加入导航，避免死链。

## 二、现状基线（代码级盘点）

### 2.1 路由与页面

| 路由 | 页面 | 职责 | 状态 |
|------|------|------|:--:|
| `/login` | `views/Login.vue` | 登录表单，调 `POST /api/v1/login`，成功后写 `iot_token` / `iot_username` 到 localStorage | ✅ |
| `/dashboard` | `views/Dashboard.vue` | 仪表盘（FastBee 式）：统计卡片条（设备总数/在线/离线/产品数）+ 最近活跃设备 + 产品概览，均复用现有接口 | ✅ |
| `/` | `views/Console.vue` | 设备列表页（菜单名「设备」）：**全宽设备列表**（工具栏：搜索 / 状态筛选 / 产品筛选 / 注册 / 批量操作 / 导出 / 批次列表 / 视图切换）+ 表格 + 分页 | ✅ |
| `/devices/:key` | `views/DeviceDetail.vue` | 设备详情 tab 工作台：设备信息 / 实时数据 / 调试 / 设备影子 / 事件记录 / 操作日志（复用 MetricCards / HistoryChart / ControlPanel / ShadowPanel） | ✅ |
| `/products` | `views/Products.vue` | 产品卡片网格页（菜单名「产品」，FastBee 式 3/2/1 列卡片：渐变图标/名称/product_key+节点标签/协议·格式·规模·时间元数据/底部「查看详情·设备列表」），搜索过滤 + 新建产品 | ✅ |
| `/products/:key` | `views/ProductDetail.vue` | 产品详情页（独立路由）：返回 + 三 tab——基础信息 / 物模型三要素 UI 编辑（enum 枚举项 + step）/ 该产品设备列表（支持 `?tab=` 定位） | ✅ |
| `/categories` | `views/Categories.vue` | **设备分组**（E4 已落地；菜单名「设备分组」，路由沿用历史路径 `/categories` 未改名）：分组卡片网格 + 组内设备抽屉 + 未分组入口 | ✅ |
| `/rules` | `views/Rules.vue` | **告警规则**（E3 尾巴）：规则表格（监测条件 / 作用范围 / 级别 / 命中动作 / 冷却 / 累计触发 / 启停开关）+ 产品·状态·关键字筛选 + 新增编辑弹窗（属性下拉取自该产品物模型 TSL、**联动下发内容用 TSL 驱动属性行编辑器，不手写 JSON**）+ 条件预览 | ✅ |

路由守卫（`router/index.js`）：无 token 访问非登录页 → 跳 `/login`；已登录访问 `/login` → 跳 `/`。

### 2.3 API 封装（`src/api/index.js`，24 个）

JWT 注入：请求拦截器加 `Authorization: Bearer <iot_token>`；响应拦截器统一处理 `code!==0` 与 401 跳登录。

| 分组 | 接口 |

| 登录 | `login` |
| 设备 | `listDevices`（分页/关键词/产品/状态筛选）、`deleteDevices`（批量删除）、`listDeviceLogs`（操作日志）、`getTsl`、`getLatestTelemetry`、`getHistoryTelemetry` |
| 命令 | `dispatchCommand`、`getCommandStatus` |
| 注册 | `registerDevice`、`registerBatch` |
| 产品/物模型 | `listProducts`、`createProduct`、`getProductTsl`、`updateProductTsl` |

### 2.4 实时机制现状（与 MVP 计划文档的差异，实盘确认）

`DeviceDetail.vue` 内有一处轮询：进入详情页后 `setInterval(loadLatest, 5000)`，仅刷新**当前设备**的最新遥测；设备列表只在挂载、搜索、筛选、翻页时刷新。MVP 计划文档曾写"设备列表 5s 轮询"，实际已收敛为"详情页最新遥测 5s 轮询"——E2 WebSocket 以当前实现为基线（改造范围：详情页轮询 → WS 推送）。

### 2.5 后端接口缺口（与 OneNET 式详情的差距，实盘确认）

后端现有 7 个 Controller（Auth/Command/Device/Product/Shadow/Telemetry/User）。与"设备详情 tab 化"直接相关的缺口：

| 能力 | 后端现状 | 前端影响 |
|------|---------|---------|
| 设备详情（单设备基础信息） | 无独立端点（列表项已含名称/状态/在线时间） | 详情页「设备信息」tab 可先复用列表数据，独立端点留待需要 |
| 事件记录 | `up/{key}/event` topic 存在，但无事件存储/查询端点 | 「事件记录」tab 需先确认事件数据链路，当前**后端接口不存在** |
| 操作记录/设备日志 | `device_log` 表存在（上下线记录），无查询端点 | 「日志」tab 需新增查询接口 |
| 设备调试 | 下发/服务调用已具备 | 「调试」tab 可直接落地 |
